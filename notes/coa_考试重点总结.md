### 模块：1.1 计算机发展历程（大纲已删，了解即可）

- 第一台电子数字计算机 ENIAC（1946），采用电子管，速度 5000 次加法/秒。
- 四代发展：电子管 → 晶体管 → 中小规模集成电路 → 大规模/超大规模集成电路。
- 摩尔定律：集成电路上可容纳的晶体管数目约每 18 个月翻一倍，性能也提升一倍。
- 机器字长 = 计算机一次整数运算所能处理的二进制位数；微型计算机发展以微处理器为标志。

### 模块：1.2 计算机系统的层次结构

#### 1.2.1 计算机系统 = 硬件 + 软件 【理解】

#### 定义
- 系统软件：操作系统、DBMS、语言处理程序、标准程序库、网络软件、服务程序。

#### 1.3.2 CPU 的性能指标 【理解】

#### 定义
**CPU 主频 = 1 / CPU 时钟周期；执行一条指令耗时 = CPI × CPU 时钟周期**

**CPU 执行时间（整个程序）= CPU 时钟周期数 / 主频 = (指令条数 × CPI) / 主频**

**IPS = 主频 / 平均 CPI；FLOPS = 每秒浮点运算次数**

- CPI：执行一条指令所需时钟周期数；不同指令 CPI 不同，相同指令 CPI 也可能变化。
- KIPS/MIPS、KFLOPS/MFLOPS/GFLOPS/TFLOPS；2021 大纲新增 PFLOPS/EFLOPS/ZFLOPS。

#### 💬 通俗理解

#### 2.1.1 进位计数制 【熟练掌握】

#### 定义
- r 进制按权展开：KₙKₙ₋₁…K₁K₀.K₋₁… = Kₙrⁿ + … + K₀r⁰ + K₋₁r⁻¹ + …。
- 二进制→八进制：3 位一组；二进制→十六进制：4 位一组。例：1111000010.01101B = 1702.32Q = 3C2.68H。
- 十进制→r 进制：整数“除基取余”（余数自低位到高位）；小数“乘基取整”（自高位到低位）。

> **★ 重点**：0.3 等十进制小数无法用二进制精确表示（无限循环），是常考小题陷阱。

- 真值 = 符合人类习惯的数（+15、-8）；机器数 = 实际存储形式（0 1111、1 1000），符号需数字化。

#### 2.1.2/2.1.3 定点数编码（原码/反码/补码/移码） 【熟练掌握】

#### 定义
- 设机器字长 n+1 位（1 位符号 + n 位数值），四种码的对比如下：

| 码制 | 整数范围 | 小数范围 | 真值 0 | 多表示的负数 |
| --- | --- | --- | --- | --- |
| 原码 | -(2ⁿ-1) ~ 2ⁿ-1 | -(1-2⁻ⁿ) ~ 1-2⁻ⁿ | +0、-0 两种 | — |
| 反码 | -(2ⁿ-1) ~ 2ⁿ-1 | -(1-2⁻ⁿ) ~ 1-2⁻ⁿ | +0、-0 两种 | — |
| 补码 | -2ⁿ ~ 2ⁿ-1 | -1 ~ 1-2⁻ⁿ | 一种 | -2ⁿ（整数）/-1（小数） |
| 移码 | -2ⁿ ~ 2ⁿ-1 | 仅整数 | 一种 | -2ⁿ |

> **★ 重点**：补码、移码的真值 0 只有一种表示，且能多表示一个负数；原码、反码有 ±0 两种。

- 8 位特例：[+0]原=00000000，[-0]原=10000000；[+0]反=00000000，[-0]反=11111111；[+0]补=[-0]补=00000000；补码整数 1,0000000 表示 -128；补码小数 1.0000000 表示 -1。
- 负数补码转原码：尾数取反、末位 +1（与求补相同）。快速求 [-x]补：[x]补 连同符号位全部取反、末位 +1。
- 移码 = 补码符号位取反，只能表示整数；移码全 0 真值最小、全 1 真值最大，方便比较大小。

#### 2.2.1 加法器与 ALU 【熟练掌握】

#### 定义
- 一位全加器：本位和 Sᵢ = Aᵢ ⊕ Bᵢ ⊕ Cᵢ₋₁；进位 Cᵢ = AᵢBᵢ + (Aᵢ ⊕ Bᵢ)Cᵢ₋₁。
- n bit 加法器 = n 个全加器串接（串行进位/行波进位）；并行进位的并行加法器所有进位同时产生，更快。

| 标志位 | 生成逻辑 | 含义 |
| --- | --- | --- |
| OF | Cₙ ⊕ Cₙ₋₁ | 带符号数加减溢出（1 溢出） |
| SF | Sₙ（结果最高位） | 带符号结果符号（1 为负） |
| ZF | 结果全 0 才为 1 | 结果是否为 0 |
| CF | C_out ⊕ C_in = Cₙ ⊕ C₀ | 无符号数加减溢出（1 溢出） |

> **★ 重点**：CF 判无符号溢出、OF 判带符号溢出；ZF 是结果全 0 才为 1。ALU 支持 k 种功能，控制信号位数 m ≥ log₂k。

#### 2.2.2 定点数移位运算 【熟练掌握】

#### 定义
| 运算 | 高/低位处理 | 效果 | 溢出/精度 |
| --- | --- | --- | --- |
| 逻辑左移 | 高位移出丢弃，低位补 0 | 无符号 ×2 | 丢弃 1 → 溢出 |
| 逻辑右移 | 低位移出丢弃，高位补 0 | 无符号 ÷2 | 丢弃 1 → 丢精度 |
| 算数左移 | 高位移出丢弃，低位补 0 | 带符号 ×2 | 符号位变化 → 溢出 |
| 算数右移 | 低位移出丢弃，高位补符号位 | 带符号 ÷2 | 丢弃 1 → 丢精度 |

#### 定义

### 模块：5.1 CPU 的功能和基本结构

> **★ 重点**：PC、MAR、MDR、IR、暂存寄存器属于“用户不可见寄存器”；通用寄存器、PSW、ACC 等用户可见。

*图 5-1  控制器基本结构*

### 模块：5.2 指令执行过程

- 三个周期：指令周期（取指+执行一条指令全部时间）→ 机器周期/CPU 周期 → 时钟周期（节拍/T 周期，最基本单位）。每个指令周期内机器周期数可不等，每个机器周期内节拍数也可不等。
- 四个工作周期（触发器标记）：取指 FE、间址 IND、执行 EX、中断 INT。四周期都访存但目的不同：取指取指令、间址取有效地址、执行取操作数、中断保存断点。
- 取指周期数据流：(PC)→MAR；1→R；M(MAR)→MDR；(MDR)→IR；(PC)+1→PC。
- 中断周期三任务：①保存断点（PC 入栈）；②形成中断服务程序入口地址；③关中断。中断隐指令不是真指令，由硬件完成。
- 三种执行方案：单指令周期、多指令周期、流水线。

### 模块：5.3 数据通路

- 数据通路 = 数据在功能部件间传送的路径。三种结构：CPU 内部单总线、多总线、专用通路。

### 模块：6.2 总线仲裁

- 多个主设备同时请求总线时，需仲裁决定总线控制权。集中仲裁（一个中央仲裁器）：链式查询、计数器定时查询、独立请求；分布式仲裁（无中央仲裁器，各设备自带仲裁逻辑）。
| 仲裁方式 | 控制线数 | 优先级 | 特点 |
| --- | --- | --- | --- |

| 计数器定时查询 | ⌈log₂n⌉ + 2 根 | 可变（改计数初值） | 灵活，但响应速度较慢 |
| 独立请求 | 2n + 1 根 | 可灵活设置 | 响应快，但线多、控制复杂 |

### 模块：6.3 总线操作和定时

| 方式 | 特点 | 适用场合 |
| --- | --- | --- |
| 同步通信（同步定时） | 统一时钟信号，各部件以统一节拍操作 | 总线长度短、各部件存取时间较一致 |
| 异步通信 | 无统一时钟，用“握手/应答”控制（不互锁/半互锁/全互锁） | 各部件速度差异大的场合 |
| 半同步通信 | 同步基础上增加 WAIT 信号，插入等待周期 | 兼顾同步简单与异步灵活 |
| 分离式通信 | 主模块发地址命令后释放总线，从模块备好数据再申请总线 | 提高总线利用率 |
![图 6-5  同步定时方式（统一时钟）](figures/ch6_sync_timing.png)
*图 6-5  同步定时方式（统一时钟）*
> **★ 重点**：同步通信以“最慢部件”为准，慢部件会拖累整体速度；异步通信通过握手自适应，但控制更复杂。分离式通信“先发后放”，从模块备好后再申请总线。

### 模块：7.1 I/O 系统基本概念

#### 7.1.1 I/O 接口的功能与组成 【理解】

#### 定义
- I/O 接口（I/O 控制器）位于主机与外设之间，功能：①实现主机与外设的通信联络；②地址译码与设备选择；③数据缓冲（协调速度差异）；④数据格式转换（串并、电平）；⑤传递控制命令；⑥反映设备状态。
- 接口组成：数据缓冲寄存器 DBR、状态/控制寄存器、端口地址译码与选址逻辑、控制逻辑。端口可分为数据端口、状态端口、控制端口。

#### 7.1.2 I/O 端口及其编址方式 【熟练掌握】

#### 定义
| 对比项 | 统一编址（存储器映射） | 独立编址（I/O 映射） |
| --- | --- | --- |
| 地址空间 | I/O 与主存统一编址，占用主存地址空间 | I/O 独立编址，不占用主存地址空间 |
| 访问指令 | 用访存指令（LOAD/STORE） | 专门 I/O 指令（IN/OUT） |
| 优点 | 指令丰富、编程灵活、无需专门译码 | I/O 地址短、译码快、不占主存 |
| 缺点 | 占用主存地址，指令长 | 需专门指令，编程较繁琐 |

> **★ 重点**：统一编址可用所有访存指令访问 I/O（灵活），但占用主存地址空间；独立编址用 IN/OUT 指令，速度快不占主存地址。408 常考二者区分。

### 模块：7.2 I/O 方式

- 程序查询方式（程序直接控制）：CPU 不断查询设备状态，设备未就绪则一直等待（轮询）。CPU 与外设串行工作，效率低，但硬件最简单。
![图 7-2  程序查询方式的流程](figures/ch7_query_flow.png)
*图 7-2  程序查询方式的流程*
- 程序中断方式：CPU 启动 I/O 后继续执行其他程序，设备就绪后向 CPU 发出中断请求，CPU 响应后转去执行中断服务程序。CPU 与外设可并行，效率较高。
- DMA 方式：外设与主存之间直接交换数据（不经 CPU），由 DMA 控制器控制，适合高速大批量数据传送。
| 对比项 | 程序查询 | 程序中断 | DMA |
| --- | --- | --- | --- |
| 数据传送方向 | CPU↔外设 | CPU↔外设 | 主存↔外设（不经 CPU） |
| 是否中断 | 否 | 是 | 否（结束时才中断） |
| CPU 参与程度 | 全程查询等待 | 传送时仍要 CPU 执行指令 | 仅预处理/后处理 |
| 适用 | 简单低速设备 | 中低速设备 | 高速大批量设备 |
| 优先级/速度 | 最低 | 中 | 最高（最快） |

### 模块：7.4 中断系统

#### 7.4.1 中断的基本概念与处理流程 【理解】

#### 定义
- 中断：CPU 在执行程序过程中，遇到异常情况或外设请求时，暂停当前程序转去处理，处理完再返回原程序继续执行。中断源分内中断（CPU 内部，如除法错、溢出）和外中断（外设请求）。
- 中断处理流程：中断请求 → 中断判优（响应优先级）→ 关中断（保存现场前）→ 保存断点和现场 → 开中断 → 执行中断服务程序 → 关中断 → 恢复现场 → 开中断 → 中断返回。
- 中断向量 = 中断服务程序的入口地址；中断向量表存放各中断源对应的入口地址。

#### 💬 通俗理解
外面来的“叫停铃”，让 CPU 立刻把控制权还给操作系统。

#### 小结

#### 7.4.3 多重中断与中断屏蔽字 【熟练掌握】

#### 定义
- 多重中断（中断嵌套）：执行中断服务程序时，允许响应更高优先级的新中断请求（需先开中断）。
- 中断屏蔽字：每位对应一个中断源，置 1 表示屏蔽该中断源；执行某中断源服务程序时，用屏蔽字屏蔽“本级及更低优先级”的中断请求。

### 模块：7.5 DMA 方式

#### 7.5.1 DMA 控制器的功能与组成 【熟练掌握】

#### 定义
- DMA 控制器功能：接收外设请求、向 CPU 申请总线控制权（HOLD/HLDA）、给出主存地址、控制数据块传送、传送结束向 CPU 发中断。
- 组成：主存地址计数器（AR）、数据块计数器（WC，记录剩余传送字数）、数据缓冲寄存器、设备地址寄存器、控制/状态逻辑、中断机构。

![图 7-5  DMA 控制器的组成](figures/ch7_dma_controller.png)

*图 7-5  DMA 控制器的组成*

> **★ 重点**：AR 每传一个字自动 +1，WC 每传一个字自动 -1，减到 0 表示一块数据传送完毕，DMA 向 CPU 发中断请求。

#### 7.5.2 DMA 传送方式（DMA 与 CPU 访问主存的协调） 【熟练掌握】

#### 定义
| 方式 | 做法 | 特点 |
| --- | --- | --- |
| 停止 CPU 访存 | DMA 传送期间 CPU 停止访存 | 简单，但 CPU 利用率低 |
| 周期挪用（周期窃取） | CPU 空闲周期 DMA 借用；冲突时 DMA 优先（或让 CPU） | CPU 与 DMA 交替访存，效率较高 |
| 交替访问 | 总线时间固定分配，CPU 与 DMA 各占一段 | 连续分配，无需申请，但硬件复杂 |

> **★ 重点**：周期挪用（周期窃取）是最常用方式；DMA 与 CPU 冲突时通常让 DMA 优先（以免外设数据丢失）。

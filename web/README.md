# CS408 全量知识讲义 Web

本版遵循唯一内容规则：

- 350 份 PDF 中的**课程知识全部是重点**，不使用 S/A/B/C 删除或隐藏内容。
- PDF 是原料和证据；网站默认展示的是重新组织后的学习正文。
- 6058 页有效文字经过清洗、动画重复合并和语义分类，新增知识不丢。
- 每份课件都提供“本节必须记”；优先识别课件末尾的知识回顾/总结。
- 图、表、公式、时序图、代码布局可从正文块直接展开对应原页。
- 广告/课程咨询页不作为 408 学习知识进入正文。

部署：
```bash
npm run check
npm run build
```
Vercel 使用仓库根目录为本 web 目录即可，输出目录为 `dist`。

# CS408 考点复习台（可直接打开）

朋友用这份即可，**不必安装 Node / npm**。

## 怎么打开（Windows）

1. 下载或克隆本仓库，进入 `Outputs` 文件夹  
2. 双击 **`打开复习台.bat`**  
3. 浏览器会打开 `http://127.0.0.1:8080/`  

关闭黑色窗口即停止。若提示端口占用，可先关掉其它占用 8080 的程序。

> 有 Python 时会优先用 `python -m http.server`；否则用系统自带 PowerShell。  
> **不要**直接双击 `index.html`（浏览器会拦截本地 JSON，页面会空白）。

## 里面有什么

- 四门课考点：定义 / 通俗理解 / 考察形式 / 记忆技巧  
- 经典例题、易错点、重点图示  
- 课件原文（文字分页；全页幻灯片图体积太大未打进此包）

## macOS / Linux

在 `Outputs` 目录执行：

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:8080/

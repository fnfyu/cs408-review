IEEE 754 定义的4种舍入模式
舍入模式
特点
⭐就近舍入（类似“0舍1入”）
IEEE默认舍入模式。类似“0舍1入”。如果3个舍弃位刚好
是 100，则若1+23bit尾数的末位为0，直接截断多余位即可；
若1+23bit尾数的末位为1，则截断多余位，并在“末位+1”
正向舍入（向 +∞ 舍入）
对正数进位（向上取整），对负数截断多余尾数
负向舍入（向 −∞ 舍入）
对负数进位（向下取整），对正数截断多余尾数
截断法（向0舍入）
直接截断多余尾数，不进位
以float型加减运算为例：
尾数仅保留 1(隐含)+23 = 24 bit。IEEE 754 规定尾数“对阶”时，至少额外保留3bit冗余位
#include <fenv.h>
// 1) 就近舍入（默认）
fesetround(FE_TONEAREST);
// 2) 正向舍入
fesetround(FE_UPWARD);
// 3) 负向舍入
fesetround(FE_DOWNWARD);
// 4) 向0舍入
fesetround(FE_TOWARDZERO);

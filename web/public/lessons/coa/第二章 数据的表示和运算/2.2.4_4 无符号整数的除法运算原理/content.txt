关于“商溢出”的进一步探讨
该除法器支持
2n bit ÷ n bit （双精度除法）
n bit ÷ nbit（单精度除法）
最终都仅保留n bit 商、n bit 余数
2n bit ÷ n bit，商的实际位数有可能超过 n bit，因此，无符号整数的双精度除法可能发生“商溢出”
n bit ÷nbit，商的实际位数不可能超过 n bit，因此，无符号整数单精度除法不可能发生“商溢出”
【例1】双精度除法商溢出
255 / 15 = 17，余数为0
1111 1111 / 1111 = 1 0001
【例2】双精度除法商未溢出
200/15 = 13，余数为5
1100 1000 / 1111 = 0 1101
【例3】单精度除法商不可能溢出
15 / 1 = 15，余数为0
0000 1111/0001 = 1111
需统一为 
2n bit ÷ n bit

第一章  计算机系统概述 
【考情速览】本章是入门章，408 统考以选择题为主，高频考点集中在：冯·诺依曼结构与现代结构的区别、
计算机系统的层次结构、体系结构与组成原理的“透明”概念、性能指标（主频/CPI/IPS/FLOPS、存储容量）
计算。“计算机发展历程”已从大纲删除，了解即可。 
1.1 计算机发展历程（大纲已删，了解即可） 
• 
第一台电子数字计算机 ENIAC（1946），采用电子管，速度 5000 次加法/秒。 
• 
四代发展：电子管 → 晶体管 → 中小规模集成电路 → 大规模/超大规模集成电路。 
• 
摩尔定律：集成电路上可容纳的晶体管数目约每 18 个月翻一倍，性能也提升一倍。 
• 
机器字长 = 计算机一次整数运算所能处理的二进制位数；微型计算机发展以微处理器为标志。 
1.2 计算机系统的层次结构 
1.2.1 计算机系统 = 硬件 + 软件 
• 
系统软件：操作系统、DBMS、语言处理程序、标准程序库、网络软件、服务程序。 
• 
应用软件：为解决某应用领域问题而编制的程序（如 QQ、Photoshop）。 
• 
三种语言：机器语言（二进制代码）、汇编语言（助记符）、高级语言（C/Java）。汇编器把汇编语言
翻译成机器语言；编译器/解释器处理高级语言。 
• 
软件与硬件在逻辑功能上等价：同一功能可用硬件实现（性能高、成本高），也可用软件实现（性能低、
成本低）。指令集体系结构 ISA 是软硬件之间的界面。 
1.2.2 计算机硬件的基本组成 
★ 冯·诺依曼机特点（必背 6 条）：①五大部件组成；②指令和数据以同等地位存于存储器、可按地址寻访；
③指令和数据用二进制表示；④指令由操作码和地址码组成；⑤存储程序；⑥以运算器为中心。 
• 
五大部件：输入设备、输出设备、存储器、运算器、控制器。 
• 
早期冯·诺依曼机“以运算器为中心”：输入/输出设备与存储器之间的数据传送都要经过运算器。 
• 
现代计算机“以存储器为中心”：CPU = 运算器 + 控制器；主机 = CPU + 主存；外设 = I/O 设备。

★ 体系结构 vs 组成原理：体系结构 = 机器语言程序员所见到的属性（指令系统、数据类型、寻址技术、I/O 
机理）；组成原理 = 如何用硬件实现这些属性，对程序员“透明”（看不见）。 
• 
“透明”= 看不见（如对程序员透明 = 程序员无需了解）；“公开透明”= 看得见。 
1.2.5 计算机系统的工作原理 
• 
从 C 源程序到可执行文件：预处理(.i) → 编译(.s 汇编) → 汇编(.o 目标) → 链接(.exe)。 
• 
“存储程序”工作方式：指令以二进制形式事先存入主存，按首地址顺序执行。 
1.3 计算机的性能指标 
1.3.1 存储器的性能指标 
总容量 = 存储单元个数 × 存储字长 (bit) = 存储单元个数 × 存储字长 / 8 (Byte) 
• 
MAR 位数反映存储单元个数（最多 2^MAR 个）；MDR 位数 = 存储字长。例：MAR=32、MDR=8 → 总
容量 = 2^32 × 8bit = 4GB。 
• 
数量单位：K=2^10，M=2^20，G=2^30，T=2^40（存储容量用）；P/E/Z 按 ×10^3 递增。 
1.3.2 CPU 的性能指标 
CPU 主频 = 1 / CPU 时钟周期；执行一条指令耗时 = CPI × CPU 时钟周期 
CPU 执行时间（整个程序）= CPU 时钟周期数 / 主频 = (指令条数 × CPI) / 主频 
IPS = 主频 / 平均 CPI；FLOPS = 每秒浮点运算次数 
• 
CPI：执行一条指令所需时钟周期数；不同指令 CPI 不同，相同指令 CPI 也可能变化。 
• 
KIPS/MIPS、KFLOPS/MFLOPS/GFLOPS/TFLOPS；2021 大纲新增 PFLOPS/EFLOPS/ZFLOPS。 
1.3.3 系统整体的性能指标 
• 
吞吐量：单位时间处理请求的数量，主要取决于主存的存取周期。 
• 
响应时间 = CPU 时间 + 等待时间（磁盘访问、存储器访问、I/O、OS 开销等）。 
• 
数据通路带宽 = 数据总线一次能并行传送信息的位数。

经典例题 
【例题】（性能计算）某 CPU 主频 1000Hz，某程序含 100 条指令，平均 CPI=3，求执行时间。 
执行时间 = 100 × 3 × (1/1000) = 0.3s。公式：CPU 执行时间 = (指令条数 × CPI) / 主频。 
【例题】（存储容量）MAR 为 32 位、MDR 为 8 位，求主存总容量。 
总容量 = 2^32 × 8bit = 2^32 Byte = 4GB。

易错点速记 
• 
冯·诺依曼“以运算器为中心”，现代计算机“以存储器为中心”，两者别搞反。 
• 
MAR 位数 → 存储单元个数（2^MAR）；MDR 位数 → 存储字长，二者含义不同。 
• 
存储容量单位 K/M/G/T 是 2 的幂（2^10 等）；数量单位（KIPS/FLOPS）的 K/M/G/T 是 10 的幂。 
• 
“透明”= 看不见；“组成原理对程序员透明”，不是“体系结构对程序员透明”。 
• 
CPU 区分指令和数据靠“指令周期阶段”，不是靠存储位置或标志位。

2.1 数制与编码 
2.1.1 进位计数制 
• 
r 进制按权展开：KₙKₙ₋₁…K₁K₀.K₋₁… = Kₙrⁿ + … + K₀r⁰ + K₋₁r⁻¹ + …。 
• 
二进制→八进制：3 位一组；二进制→十六进制：4 位一组。例：1111000010.01101B = 1702.32Q = 
3C2.68H。 
• 
十进制→r 进制：整数“除基取余”（余数自低位到高位）；小数“乘基取整”（自高位到低位）。 
★ 0.3 等十进制小数无法用二进制精确表示（无限循环），是常考小题陷阱。 
• 
真值 = 符合人类习惯的数（+15、-8）；机器数 = 实际存储形式（0 1111、1 1000），符号需数字化。

2.1.4 C 语言整数类型与转换 
•

•

【例题】（扩展操作码）指令字长 16 位、地址码各 4 位，设计 15 条三地址 + 12 条二地址 + 62 条一地址 +

【例题】（寻址方式访存次数）某指令为二地址指令，采用寄存器间接寻址，求执行期间访存次数。 
寄存器间接 EA=(Ri)，需访存 1 次取操作数；加上另一操作数及写回，需结合题意。仅对一个操作数寄存器
间接 = 1 次访存。 
【例题】（基址寻址）程序原从地址 0 存放、变量 a 在地址 5；现搬到地址 100，如何不改指令地址码访问 
a？ 
用基址寻址 EA=(BR)+A：BR=100，A=5，则 EA=105，无需修改指令。基址寄存器面向 OS。 
【例题】（相对寻址）for 循环主体原在地址 2~5，搬到 M~M+3，跳转指令地址码应写多少？ 
用相对寻址，位移量 = 2 - (M+4) = 相对下一条指令的偏移，写补码 -4 类值；EA=(PC)+A，取指后 PC=M+4，
跳回 M。 
【例题】（函数调用）函数 P(x,y) 内局部变量 temp1、temp2、sum，参数 x、y 如何访问？返回值如何传？ 
局部变量用 [ebp-4/-8/-12]，参数用 [ebp+8](x)、[ebp+12](y)，返回值 sum=x+y 通过 eax 返回。开头 push 
ebp;mov ebp,esp（enter），结尾 mov esp,ebp;pop ebp（leave）。 
易错点速记 
• 
访存次数通常指“指令执行期间”，不含取指 1 次，看清题干口径。 
• 
相对寻址基准是“下一条指令”，不是当前指令。 
• 
基址 BR 面向 OS 内容不变、变址 IX 面向用户内容可变。 
• 
n 位补码立即数范围 -2^(n-1) ~ 2^(n-1)-1，不是 0~2ⁿ-1。

5.1 CPU 的功能和基本结构 
• 
CPU 五大功能：指令控制、操作控制、时间控制、数据加工、中断处理。 
• 
运算器组成：ALU、通用寄存器组、暂存寄存器、ACC、PSW 程序状态字（OF/SF/ZF/CF）、移位器、
计数器。 
• 
控制器组成：PC、IR、指令译码器 ID、微操作信号发生器（组合逻辑型/存储逻辑型）、时序系统、
MAR、MDR。 
★ PC、MAR、MDR、IR、暂存寄存器属于“用户不可见寄存器”；通用寄存器、PSW、ACC 等用户可见。

5.2 指令执行过程 
• 
三个周期：指令周期（取指+执行一条指令全部时间）→ 机器周期/CPU 周期 → 时钟周期（节拍/T 周期，
最基本单位）。每个指令周期内机器周期数可不等，每个机器周期内节拍数也可不等。 
• 
四个工作周期（触发器标记）：取指 FE、间址 IND、执行 EX、中断 INT。四周期都访存但目的不同：
取指取指令、间址取有效地址、执行取操作数、中断保存断点。

5.4 控制器 
5.4.1 硬布线控制器 
• 
微命令与微操作一一对应。控制信号由组合逻辑电路根据“指令操作码 + 机器周期 + 节拍信号 + 机器状

•

•

MDR→IR、OP(IR)→ID、(PC)+1→PC。 
★ 硬布线特点：执行速度快、扩充难，用于 RISC；微程序易扩充、较慢，用于 CISC。

5.4.2 微程序控制器 
• 
核心思想：程序=指令序列，微程序=微指令序列；一条指令对应一个微程序；微命令与微操作一一对应，
一条微指令可含多个微命令。 
• 
结构：CM 控制存储器（存微程序，用 ROM）、CMAR(μPC 微地址寄存器)、地址译码器、CMDR(μIR)、
微地址形成部件+顺序逻辑。 
★ n 条机器指令 → CM 中微程序数至少 n+1 个（公用取指微程序 + n 个执行微程序）。 
 
图 5-3  微程序控制器基本结构 
5.4.3 微指令的设计 
• 
格式：操作控制字段 + 顺序控制字段（下地址）。水平型（能定义多个并行微命令，微程序短执行快）
vs 垂直型（一条只定义一个微命令，短但慢）vs 混合型。 
• 
编码方式：直接编码（每位一个微命令，字长过长）；字段直接编码（分段译码，互斥同段相容异段，
每段留 000 不操作）；字段间接编码（辅助手段）。 
★ 字段直接编码：m 个互斥微命令需 ⌈log₂(m+1)⌉ 位（留 1 个不操作状态），3 位最多表示 7 个互斥微命令
（不是 8 个）。 
• 
微地址形成方式：下地址字段直接指出（断定方式）、按操作码形成、增量计数器 (CMAR)+1、分支转
移、测试网络、硬件产生入口地址。 
5.4.4 微程序控制单元设计 
• 
设计 4 步：分析微操作序列 → 写微操作命令及节拍安排 → 确定微指令格式 → 编写微指令码点。 
★ 微程序控制器比硬布线慢（多一步取下一条微指令地址的节拍），取指周期硬布线 T0/T1/T2 三节拍，微
程序需 T0/T2/T4 + T1/T3/T5 定下地址。

5.6 指令流水线 
5.6.1 基本概念与性能指标 
• 
设 k 段流水线、n 个任务、每段耗时 Δt： 
流水线完成时间 T_k = (k + n - 1)Δt 
吞吐率 TP = n / [(k+n-1)Δt]；极限 TP_max = 1/Δt 
加速比 S = nk / (k+n-1)；极限 S_max = k 
效率 E = n / (k+n-1)；极限 E_max = 1 
★ 机器周期 = 各段最长耗时（取齐）；每段后需缓冲寄存器（锁存器）保存结果供下一段用。

5.6.3 五段式指令流水线 
• 
五段：IF 取指 → ID 译码取数 → EX 执行 → M 访存 → WB 写回。 
• 
运算类 M 段空；LOAD 在 M 段取数；STORE 在 M 段写、WB 空；条件转移在 M 段写回 PC；无条件转
移目标 PC 尽量提前在 EX 段写回（越早越减少控制冲突）。 
★ 只有上一条指令进入 ID 段后，下一条指令才能开始 IF 段（否则覆盖 IF 段锁存器）。RISC 只有 
LOAD/STORE 访存。 
 
图 5-5  五段式指令流水线 
5.7 多处理器（了解即可，只考选择题） 
• 
Flynn 分类：SISD（单指令单数据，非数据级并行）、SIMD（单指令多数据，数据级并行）、MISD
（现实中不存在）、MIMD（多指令多数据，线程级并行）。 
• 
多处理器系统（SMP 共享内存，靠 LOAD/STORE 通信）vs 多计算机系统（私有内存，只能消息传递）。 
经典例题 
【例题】（字段直接编码位数）33 个微命令分 5 个互斥类，分别含 7、3、12、5、6 个，操作控制字段至少
几位？ 
每段留 1 个不操作状态：7→⌈log₂8⌉=3、3→2、12→⌈log₂13⌉=4、5→3、6→3，合计 3+2+4+3+3=15 位。直接
编码则需 33 位。 
【例题】（断定方式地址位数）32 条指令，公用取指微程序 2 条微指令，各指令微程序平均 4 条，下地址
字段至少几位？ 
总微指令数 = 32×4 + 2 = 130；2⁷=128 < 130 ≤ 2⁸=256，故下地址字段至少 8 位。 
【例题】（流水线性能）4 段流水线、每条指令 4Δt，执行 100 条指令，求吞吐率、加速比、效率。 
T_k=(4+100-1)Δt=103Δt；TP=100/103Δt；加速比 S=100×4/103≈3.88；效率 E=100/103≈0.97。

6.1 总线概述 
6.1.1 总线的基本概念与特性 
• 
总线：一组能为多个部件“分时共享”的公共信息传送线路。分时（同一时刻只允许一个部件发送）+ 共
享（可挂多个部件）是总线最本质的特征。 
• 
四大特性：机械特性（尺寸、形状、引脚）、电气特性（传输方向、有效电平范围）、功能特性（每根
线的功能）、时间特性（信号时序关系）。 
★ “分时共享”是总线的核心：发送必须分时（独占），接收可以共享（广播）。

•

•

•

7.4 中断系统 
7.4.1 中断的基本概念与处理流程 
• 
中断：CPU 在执行程序过程中，遇到异常情况或外设请求时，暂停当前程序转去处理，处理完再返回原
程序继续执行。中断源分内中断（CPU 内部，如除法错、溢出）和外中断（外设请求）。 
• 
中断处理流程：中断请求 → 中断判优（响应优先级）→ 关中断（保存现场前）→ 保存断点和现场 → 开
中断 → 执行中断服务程序 → 关中断 → 恢复现场 → 开中断 → 中断返回。 
• 
中断向量 = 中断服务程序的入口地址；中断向量表存放各中断源对应的入口地址。 
7.4.2 中断隐指令 
• 
中断隐指令不是一条真正的指令，而是由硬件在中断响应时自动完成的三个操作： 
• 
①关中断；②保存断点（PC 值入栈/保存）；③引出中断服务程序（形成入口地址并送入 PC）。 
 
图 7-3  中断隐指令（硬件完成的三个任务） 
★ 中断隐指令由硬件完成、无操作码，故“不是指令”。它与中断服务程序（软件指令）不同。 
7.4.3 多重中断与中断屏蔽字 
• 
多重中断（中断嵌套）：执行中断服务程序时，允许响应更高优先级的新中断请求（需先开中断）。 
• 
中断屏蔽字：每位对应一个中断源，置 1 表示屏蔽该中断源；执行某中断源服务程序时，用屏蔽字屏蔽
“本级及更低优先级”的中断请求。

位，求每秒最多传送的字节数。 
9600/11 ≈ 872 帧/秒；每帧含 8 位数据 = 1 字节，故约 872 字节/秒。

少。 
1024×768×24 bit = 18874368 bit = 2359296 Byte ≈ 2.25MB；实际取 2 的幂次，至少需 4MB 显存。

•

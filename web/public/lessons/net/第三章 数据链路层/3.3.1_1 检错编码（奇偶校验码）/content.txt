奇偶校验码
奇校验码：整个校验码（有效信息位和校验位）中“1”的个数为奇数。
偶校验码：整个校验码（有效信息位和校验位）中“1”的个数为偶数。
【例】给出两个编码1001101和1010111的奇校验码和偶校验码。
设最高位为校验位，余7位是信息位，则对应的奇偶校验码为：
奇校验：            1001101                      1010111
_                                   _
1                                  0                                  
偶校验：            1001101                      1010111
_                                   _
0                                  1

异或运算
【例】给出两个编码1001101和1010111的奇校验码和偶校验码。
设最高位为校验位，余7位是信息位，则对应的奇偶校验码为：
奇校验：            1001101                      1010111
_                                   _
1                                  0                                  
偶校验：            1001101                      1010111
_                                   _
0                                  1                                  
偶校验的硬件实现：各信息进行异或（模2加）运算，得到的结果即为偶校验位
Å：异或（模2加）
0 Å 0  =  0
0 Å 1  =  1
1 Å 0  =  1
1 Å 1  =  0
求偶校验位：
1 Å 0 Å 0 Å 1 Å 1 Å 0 Å 1 = 0
1 Å 0 Å 1 Å 0 Å 1 Å 1 Å 1 = 1
进行偶校验（所有位进行异或，若结果为1说明出错）：
0 Å 1 Å 0 Å 0 Å 1 Å 1 Å 0 Å 1 = 0
1 Å 1 Å 0 Å 1 Å 0 Å 1 Å 1 Å 0 = 1
1 Å 1 Å 0 Å 1 Å 0 Å 1 Å 0 Å 0 = 0
无法检测出
偶数位错误
两比特相“异”
时，结果为1

# 数据结构课件精读重写规范（给子代理）

目标：把 `organized-lessons.json` 里数据结构某几节的「整理正文」从 OCR 碎片，重写成**可直接复习的完整讲义**。

## 硬性要求

1. **细读** `web/_ds_chN_dump.txt` 中对应 `==== ds-xxx` 段落的全部课件原文；动画重复页合并，但**新增知识点不得丢**。
2. 广告页/“仅供娱乐”番外可精简，但正式考点必须完整。整份 PDF 都是重点，不得用“考试不考”为由删减正式课件内容。
3. 输出**合法 JSON**，结构与 `web/content/ds/ch3.json` / `ch6a.json` 一致：

```json
{
  "chapter": "第X章 ...",
  "chapter_order": X,
  "rewritten_at": "2026-09-07",
  "source": "细读王道课件 page_texts",
  "lessons": {
    "ds-0XX": {
      "blocks": [
        {
          "heading": "标题",
          "kind": "概念与原理|规则与易错|过程与算法|对比辨析|公式/代码/计算|例题与应用|图示/结论",
          "pages": [1, 2],
          "lines": ["完整通顺的中文考点句，不要 OCR 断行碎片", "..."],
          "visual_only": false
        }
      ],
      "must_memorize": [
        { "text": "可背诵的考点句", "page": 9 }
      ]
    }
  }
}
```

4. 每个 lesson：`blocks` 建议 4–12 个（页数很多的算法课可到 12–16）；`must_memorize` 建议 5–12 条；`lines` 写完整句子/要点，含 ★重点、易错、对比、公式、步骤、复杂度。
5. 图示为主的页：`visual_only: true`，但仍要写清图在讲什么、结论是什么。
6. 例题/公式块用 kind `例题与应用` 或 `公式/代码/计算`。
7. **只写你被分配的 lesson id**，写入指定输出 JSON 文件。
8. 写完后用 `JSON.parse` 自检；文件必须 UTF-8。

## 质量标准（对照 ch3.json / ch6a.json）

- 不是原文粘贴，而是消化后的讲义。
- 覆盖 dump 中每一页有效知识（动画帧合并叙述即可）。
- 必记条目应是真正考点（定义、性质、步骤、复杂度、易错对比），不是「Tips」「学习提示」之类无效句。
- 算法类：写清思想、步骤、数据结构辅助、时间/空间复杂度、适用条件、与同类算法对比。

# 计算机网络课件精读重写规范（给子代理）

目标：把 `organized-lessons.json` 里计算机网络某几节的「整理正文」从 OCR 碎片，重写成**可直接复习的完整讲义**。

## 硬性要求

1. **细读** `web/_cn_chN_dump.txt` 中对应 `==== cn-xxx` 段落的全部课件原文；动画重复页合并，但**新增知识点不得丢**。
2. 广告页/“仅供娱乐”番外可精简，但正式考点必须完整。整份 PDF 都是重点，不得用“考试不考”为由删减正式课件内容。
3. 有「上课手稿」与「纯净版」两套课时：两套都要重写；手稿版可多保留课堂口诀/易错提醒，纯净版以考点完整为准，二者知识点不得互相矛盾。
4. 输出**合法 JSON**，结构与 `web/content/os/ch1.json` / `web/content/cn/ch1.json` 一致：

```json
{
  "chapter": "第X章 ...",
  "chapter_order": X,
  "rewritten_at": "2026-09-10",
  "source": "细读王道课件 page_texts",
  "lessons": {
    "cn-0XX": {
      "blocks": [
        {
          "heading": "标题",
          "kind": "概念与原理|规则与易错|过程与算法|对比辨析|公式/代码/计算|例题与应用|图示/结论",
          "pages": [1, 2],
          "lines": ["完整通顺的中文考点句，不要 OCR 断行碎片", "..."],
          "visual_only": false
        }
      ],
      "must_memorize": [
        { "text": "可背诵的考点句", "page": 9 }
      ]
    }
  }
}
```

5. 每个 lesson：`blocks` 建议 4–12 个（页数很多的协议/算法课可到 12–18）；`must_memorize` 建议 5–12 条；`lines` 写完整句子/要点，含 ★重点、易错、对比、公式、步骤、适用范围。
6. 图示为主的页：`visual_only: true`，但仍要写清图在讲什么、结论是什么。
7. 例题/公式块用 kind `例题与应用` 或 `公式/代码/计算`。
8. **只写你被分配的 lesson id**，写入指定输出 JSON 文件。
9. 写完后用 `JSON.parse` 自检；文件必须 UTF-8。

## 质量标准（对照 content/os/ch1.json）

- 不是原文粘贴，而是消化后的讲义。
- 覆盖 dump 中每一页有效知识（动画帧合并叙述即可）。
- 必记条目应是真正考点（定义、性质、步骤、公式、协议字段、易错对比），不是「Tips」「学习提示」之类无效句。
- 协议类：写清问题背景、工作原理、关键字段/状态、与同类协议对比、408 常见易错点。
- 计算类：写清公式、单位、典型例题步骤与结论。
